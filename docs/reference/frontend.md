# Frontend

## Spec

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `foremanRef` | string | Yes | | Foreman served by this Frontend, in the same namespace |
| `replicas` | integer | No | `2` | Frontend pods |
| `image` | [image](index.md#image) | No | | Frontend image |
| `tls.server` | [tls](index.md#tls) | Yes | | Certificate presented to clients |
| `tls.clientCA` | [tls](index.md#tls) | Yes | | CA that verifies client certificates. Only `ca.crt` of the Secret is used |
| `exposure.type` | string | No | `Auto` | `Auto`, `LoadBalancer`, `Route`, `TLSRoute`, or `ClusterIP` |
| `exposure.gatewayRef.name` | string | For `TLSRoute` | | Gateway name |
| `exposure.gatewayRef.namespace` | string | No | Frontend namespace | Gateway namespace |
| `exposure.gatewayRef.tlsSectionName` | string | No | | Listener with TLS passthrough for the TLSRoute |
| `exposure.gatewayRef.httpSectionName` | string | No | | Listener for the HTTPRoute used by installers. Without it, no HTTPRoute is created and an existing one is deleted |
| `exposure.annotations` | map | No | | Added to the Service for `LoadBalancer` and `ClusterIP`, or to the Route for `Route` |

## Status

| Field | Type | Description |
|---|---|---|
| `observedGeneration` | integer | Last processed generation |
| `phase` | string | `Pending`, `Progressing`, `Running`, or `Failed` |
| `conditions` | []Condition | See [Conditions](index.md#conditions) |

## Created objects

| Object | Name | Notes |
|---|---|---|
| Certificate | `<name>-server` | Only with `tls.server.issuerRef`. DNS names are the Foreman `fqdn` and `aliases` |
| Certificate | `<name>-client-ca` | Only with `tls.clientCA.issuerRef`. A small client certificate, requested only to obtain the issuer CA in `ca.crt` |
| ConfigMap | `<name>` | Apache configuration generated by the operator |
| Deployment | `<name>` | Apache `httpd` on ports 8443 (HTTPS) and 8080 (HTTP) |
| Service | `<name>` | Ports 443 and 80. Type `LoadBalancer` for exposure `LoadBalancer`, otherwise `ClusterIP` |
| Route | `<name>` | Exposure `Route`, or `Auto` on OpenShift. Host is the Foreman `fqdn`, termination `passthrough` |
| TLSRoute | `<name>` | Exposure `TLSRoute`. Hostnames are the Foreman `fqdn` and `aliases` |
| HTTPRoute | `<name>` | Exposure `TLSRoute` with `httpSectionName` set |

`Auto` resolves to `Route` when the cluster serves the OpenShift Route API, and to `LoadBalancer` otherwise. `Route` and `TLSRoute` fail with a reconcile error when the API is not installed.
